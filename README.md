## ⌚ Watch Gallery

**Watch Gallery** is a modern watch discovery web application where users can explore premium timepieces, browse exclusive watch collections, view detailed product information, and organize their favorite watches into personalized Cart and Wishlist collections.

### || Project Overview

Watch Gallery is a modern watch discovery platform where users can explore premium timepieces, view detailed product information, and manage their favorite watches through personalized Cart and Wishlist collections.

Built with **React and modern frontend technologies**, the application features dynamic data handling, persistent storage, interactive price statistics, and a responsive user interface.

---


### ✨ Key Features

- **Explore Watches** — Browse a curated collection of watches with essential product information.
- **Detailed Watch View** — Access comprehensive information about individual timepieces.
- **Cart Management** — Add and manage selected watches in a personalized shopping cart.
- **Wishlist Management** — Save favorite watches for future consideration.
- **Duplicate Validation** — Prevent duplicate entries when adding watches to collections.
- **Persistent Cart Storage** — Retain cart information using browser localStorage.
- **Dynamic Statistics** — Visualize and compare watch prices through interactive bar charts.
- **Interactive Navigation** — Navigate seamlessly between pages and watch collections.
- **Responsive Interface** — Enjoy a consistent browsing experience across mobile, tablet, and desktop devices.

### 🔌 Data Integration

The project uses a local `watch-data.json` file to store watch information, including product names, brands, prices, images, and descriptions.

Data is fetched using JavaScript's `fetch()` and handled with **Promises and React's `use()`** to retrieve watch collections dynamically.

React's **Suspense** is used to manage loading states while asynchronous data is being resolved.
